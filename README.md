# 🤖 AI Quiz Generator

An AI-powered quiz generation application that automatically creates quizzes from user-provided topics or content. It helps students and learners practice concepts, test their knowledge, and prepare for exams efficiently.

## ✨ Features

- 🤖 AI-powered quiz generation
- 📝 Generate multiple-choice questions (MCQs)
- 🎯 Automatic answer generation
- 📚 Generate quizzes from different topics
- ⚡ Fast and easy to use
- 🎨 Simple and user-friendly interface
- 📊 Interactive quiz experience
- 🔄 Generate new quizzes anytime

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Python-dotenv
